## 폴더

| 위치 | 내용 |
|---|---|
| app | 서비스 화면·API |
| lib / src/lib | 진단·인증·저장 공통 기능 |
| data / config | 입시 근거와 설정 |
| public | 서비스에서 사용하는 로고·이미지 |
| scripts | 입시 자료 처리·검증·운영 도구 |
| docs | 기획·기술·검증·배포 기록 |
| fly | PocketBase 배포 자료 |

## 실행

- 설치: `npm ci`
- 개발: `npm run dev`
- 배포용 빌드: `npm run build`
- 실행: `npm start`

GitHub 저장소 이름과 Vercel 프로젝트 식별자는 기존 연결을 유지합니다. 로컬 폴더명만 수프리마랩으로 변경합니다.

기존 입시 데이터와 권한 구조의 확인 사항은 통합 기획안 9절을 참조하세요. 현재 배포·정리 결과는 docs/2026-11-13_배포정리.md에서 별도로 관리합니다.
