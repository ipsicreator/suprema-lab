# 수프리마 랩 · 학원용 앱 연동

기준일: 2026-11-13

## 서비스 구분

| 구분 | 수프리마 랩 | 학원용 앱 |
|---|---|---|
| 대상 | 본사 공통 자료·입시 기준·진단 | 학원 관리자·담당 컨설턴트 |
| 주소 | https://suprema-lab.vercel.app | https://consultantapp.vercel.app |
| GitHub | ipsicreator/suprema-lab | ipsicreator/consultant-app |

| 로컬 위치 | 수프리마랩 | 수프리마랩/학원용앱 (별도 저장소) |

기존 플랫폼 프로젝트와 저장소는 동일 ID·이력·설정을 유지하며 이름을 변경한다. 새 프로젝트를 중복 생성하거나 운영 데이터 저장소를 삭제하지 않는다. 과거 명칭이 남은 기술·검증 기록은 변경 이력이며 현재 서비스 명칭이 아니다. 기존 PocketBase 서비스·컬렉션 식별자는 데이터 보존을 위해 유지한다.

## 기능과 자료 흐름

- 본사 관리자는 수프리마 랩에서 공통 입결 파일을 검증·반영·복원한다.
- 학원용 앱은 파일·소스를 복사하지 않고 수프리마 랩 /api/admissions의 활성 자료를 읽는다. 활성 자료가 없거나 조회에 실패하면 실제 상태를 표시한다.
- 학원 계정은 PocketBase users로 로그인하고, 연결된 suprima_profiles의 본인 계정·역할·academy_id와 같은 학원의 활성 suprima_licenses를 확인한다.
- 프로필·학원·이용권을 자동 생성하거나 임의 연결하지 않는다. 관리자는 소속 학원 범위에서 조회한다.
- 컨설턴트의 담당 학생 관계는 실제 저장소의 배정 필드가 설정되어야 한다. 미확인 상태에서 다른 학생을 임의로 열지 않는다.
- 학원 앱의 AI 요청은 수프리마 랩 /api/academy/ai로 보낸다. 사용자 토큰·소속·역할·활성 이용권을 서버에서 검증한다.
- 수프리마 랩의 직접 AI 키가 없으면 허용된 학원 서버 /api/academy-ai로 전달한다. 학원 서버도 별도로 인증·소속·이용권을 검증하고 기존 서버 환경변수로 AI를 호출한다.
- 기존 VITE_GEMINI_API_KEY는 학원 서버에서만 읽는다. 브라우저 코드에서는 키와 Gemini SDK를 읽거나 호출하지 않는다. 저장된 Secret 값을 추출·복사하지 않았다.
- 알라딘 API 직접 호출은 제거한다. 도서는 검색 링크를 제공하고 API로 검증된 서지 정보로 표현하지 않는다.

## 운영 환경변수

수프리마 랩의 공개 설정: NEXT_PUBLIC_APP_NAME, NEXT_PUBLIC_SITE_URL, NEXT_PUBLIC_ACADEMY_APP_URL. 서버 설정: ACADEMY_APP_ORIGINS, ACADEMY_AI_SERVICE_URL, ADMIN_EMAILS 및 기존 AUTH_SECRET·PB 자격. 기존 공개 화면의 관리자 지정은 같은 계정의 서버 ADMIN_EMAILS로 옮긴다. 비밀값과 관리자 이메일 값은 이 문서에 기록하지 않는다.

학원 앱의 공개 설정: VITE_APP_NAME, VITE_SUPREMA_LAB_URL, VITE_POCKETBASE_URL. 실제 배정 관계를 확인한 경우에만 VITE_STUDENT_CONSULTANT_FIELD를 설정한다. 기존 VITE_GEMINI_API_KEY는 서버 전용 호환 이름이며 브라우저에 노출하지 않는다. VITE_ALADIN_TTB_KEY는 사용하지 않는다.

두 앱은 같은 PocketBase를 사용해야 한다. 운영 앱의 공개 연결 주소에서 동일 저장소를 사용하는 것을 확인했다. 환경변수 변경은 새 배포에 적용하므로 설정 변경 후 배포를 확인한다.

## 제한과 검증 범위

- 기존 입결 전체 파일 검증은 임시 저장소에서 수행했으며 운영 자료 활성화는 별도다.
- 실제 학원 사용자·학생 배정 관계 및 PocketBase API 규칙은 운영 계정으로 확인해야 한다. 클라이언트 필터만으로 저장소 접근 분리 완료를 주장하지 않는다.
- Google 승인 콜백에 새 도메인을 추가했으며 실제 Google 로그인과 관리자 홈 접속을 확인했다. 네이버·카카오 로그인은 이번 검증 범위에 포함하지 않는다.
- 실제 학생 원문을 AI에 전송하거나 결과를 발송하지 않고, 잘못된 토큰·소속·이용권·출처·자료 실패 경로를 시험한다.
- 오래된 파일 복사 동기화 스크립트는 읽기 전용 공유 API 연결 확인으로 교체했다.

## 폴더 정리

기존 .cache/suprema-platform 운영 파일은 .cache/suprema-lab으로 보존 이동한다. 바탕화면 suprema-platform 폴더는 비어 있으나 현재 작업 프로그램이 사용 중이면 삭제가 거부될 수 있다. 내용이 있으면 자동 삭제하지 않는다. 최종 삭제 상태는 실제 확인 결과로 구분한다.

## 최종 반영 및 확인

- 기존 플랫폼 주소는 새 수프리마 랩 주소로 308 영구 이동한다. 기존 주소를 타인이 재사용하지 않도록 연결을 보존한다.
- 수프리마 랩 자동 검증 62개 통과. 학원 앱 자동 검증 18개 통과.
- 학원 앱 운영 배포: 178ed10. 수프리마 랩의 인증·권한·연동 설정을 포함해 최종 재배포한다.
- 과거 로그인 시험 파일의 내장 자격과 인증 응답 출력은 제거했다. 과거 저장소 이력에 남은 해당 계정 비밀번호는 소유자가 변경해야 한다.
