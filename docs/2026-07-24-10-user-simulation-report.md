## 목적
- 실제 사용 흐름 기준으로 `/`, `/intro`, `/diagnosis`, `/diagnosis/step1~4`, `/report`, `/exploration`을 10명의 가상 사용자 관점에서 점검했다.
- 화면 깨짐, 로고 일관성, 단계 연결, 결과 보고서 가독성, 사용 흐름 완결성을 함께 평가했다.

## 공통 점검 기준
- 브랜드 로고가 모든 핵심 화면에 동일하게 표시되는가
- 인트로에서 진단 시작으로 자연스럽게 진입되는가
- 1~4단계가 끊기지 않고 이어지는가
- 결과 보고서가 실제 운영 화면처럼 읽히는가
- 탐구/독서 화면이 별도 서비스로도 동작하는가
- 빌드가 통과하는가
