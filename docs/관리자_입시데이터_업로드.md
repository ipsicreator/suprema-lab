# 관리자 입시 데이터 파일 반영

## 이용 방법

1. `/admin`에서 **입시 데이터 관리**를 연다. 직접 주소는 `/admin/admissions`다.
2. 관리자 계정으로 로그인한다.
3. 엑셀(.xlsx, .xls), CSV, TSV 중 하나를 선택한다. 최대 원본 파일 크기는 20MB다.
4. 반영할 시트를 선택한다. ‘전체’ 시트가 있으면 우선 선택한다.
5. **검증 및 미리보기**를 누른다. 이 단계는 임시 저장이며 서비스 데이터는 바뀌지 않는다.
6. 전형 수·대학 수·입결 수치·경고와 미리보기를 확인한다.
7. 전체 교체 확인란에 체크하고 **서비스에 전체 반영**을 누른다.
8. 문제가 있으면 **반영 이력**에서 이전 버전을 선택해 복원한다.

반영된 데이터는 입시위치 진단 검색 화면, 입학전략 시뮬레이션, `/api/diagnosis`에서 함께 읽는다. 새로 열거나 새로고침한 화면에 적용되며 코드 재배포는 필요하지 않다. 기존에 열어 둔 화면은 새로고침한다.

## 파일 형식과 검증

대학명(대학교), 모집단위(모집단위명), 전형유형, 전형명은 필수다. 첫 30행 안에서 실제 열 제목을 자동으로 찾는다. 최대 50,000개 전형을 반영한다. 여러 시트는 각각 검토할 수 있으나 한 번에 선택한 한 시트가 공통 데이터 전체를 교체한다. 추가 병합 기능은 제공하지 않는다.

V7.24의 3행 헤더와 줄바꿈이 있는 열 제목을 지원한다. 원본 파일은 수정하지 않는다. 평균과 50%/70%컷을 구분하고, 남녀별 값처럼 한 셀에 여러 값이 있는 경우 원문을 보존하면서 수치 판정에서 제외한다. 등급 범위를 벗어난 일반 입결도 경고와 함께 제외하며, 명시적인 50%/70% 입력이 잘못된 경우 반영을 차단한다. 빈 데이터·필수 항목 누락·지원하지 않는 형식은 반영하지 않는다.

큰 원본 엑셀은 브라우저에서 해석한 뒤 검증용 행 데이터만 압축 전송한다. 전송 한도는 압축 후 3MB이며 이를 넘으면 원본을 보존한 채 필요 없는 열을 줄여야 한다. 복잡한 서식·수식은 가져오지 않으며 엑셀에 저장된 값으로 처리한다. CSV/TSV는 UTF-8과 한글 EUC-KR 인코딩을 지원한다.

## 배포 설정

서버의 `ADMIN_EMAILS`에 관리자 이메일을 쉼표로 구분해 설정한다. 화면의 이름 입력이나 공개 환경변수만으로 관리자 권한을 부여하지 않는다.

Vercel에서 반영과 복원을 사용하려면 다음 서버 전용 환경변수가 필요하다.

- `PB_URL` 또는 `NEXT_PUBLIC_PB_URL`: 기존 PocketBase 주소
- `PB_ADMIN_EMAIL`, `PB_ADMIN_PASSWORD`: PocketBase 관리자 계정
- 기존 로그인 제공자 및 `AUTH_SECRET` 설정

첫 검증 업로드에서 비공개 `suprema_admission_revisions`, `suprema_admission_active` 컬렉션을 준비한다. 버전 파일은 비공개 압축 스냅샷으로 저장하고, 활성 버전 포인터 하나를 전환한다. 검증·저장이 실패하면 활성 버전은 바뀌지 않는다. 최근 20개 반영 버전을 화면에서 복원할 수 있다.

Vercel에서는 임시 파일시스템 저장을 사용하지 않는다. 영구 저장소 설정이 없으면 화면에 설정 오류를 표시한다. 로컬에서 PocketBase를 구성하지 않으면 `.cache/admissions`에 저장하며, 이 경로는 Git과 배포 대상에서 제외된다. 시험 시 `ADMISSIONS_STORAGE_DIR`로 별도 경로를 지정할 수 있다.

이 기능은 공통 입시 근거를 변경하는 본사 관리자용이다. 학원별 관리자 권한 체계 확장은 별도 기획 범위다.

## 검증

- `node --test scripts/admissions-import.test.cjs scripts/admissions-store.test.cjs`
- `node scripts/admissions-upload.integration.cjs` (먼저 배포용 빌드 필요)
- `npm run build`

실제 클라우드 데이터에 대한 반영·배포는 이 문서 작성과 로컬 검증에 포함되지 않는다.
