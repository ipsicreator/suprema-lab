# GitHub·Vercel 배포 및 파일 정리

기준일: 2026-11-13

## 정리 기준과 결과

- 실행 코드, 데이터·설정, 인증·배포 설정, 원본과 기존 검증 도구 보존.
- public/captures의 과거 화면을 화면구성_플로우별/10_과거캡처_보관으로 이동하고 SHA-256 대조.
- outputs/qa의 중복 캡처는 검토 폴더 보관본과 해시가 동일한 파일만 제거.
- 실제 로컬 운영 정보가 있는 .cache는 유지하되 Git·배포 대상에서 제외.
- 화면 검토 자료, 문서, 에이전트 상태·도구는 Vercel 업로드 대상에서 제외.
- node_modules와 검증된 빌드 산출물은 로컬 재실행 편의를 위해 유지.

- GitHub: ipsicreator/suprema-platform / master
- Vercel: 기존 연결 프로젝트 및 suprema-platform.vercel.app 도메인 유지
- 로컬 프로젝트 폴더: 수프리마랩
