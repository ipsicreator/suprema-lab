# 수프리마랩 앱 점검 및 수정 결과

기준일: 2026-11-13

## 확정 구조

마스터 → 본사 관리자 → 학원(학원 관리자) → 담당 컨설턴트 → 배정 학생.

구조·권한·모듈·데이터 책임의 기준은 [전체 구조 확정안](전체구조_확정안.md)으로 통합했다. 현재 이메일 목록 기반 관리자 인증과 향후 학원별 역할·학생 배정 구현은 구분한다.

## 수정한 주요 문제

- 입결 근거가 없는데 ‘적정’ 판정이 나오던 오류를 ‘판단 보류’로 수정.
- 일부 연도가 빠질 때 연도 가중치가 다른 연도로 이동하던 오류 수정.
- 대학·캠퍼스·모집단위·전형이 일치하지 않아도 임의의 입결을 가져오던 경로 제거.
- 평균 입결을 50%·70%컷으로 취급하던 처리 제거.
- 잘못된 성적·전형 요청은 명확한 입력 오류로 응답.
- 마지막 진단 화면을 실제 반영 데이터와 진단 API에 연결하고 수정 후 기존 결과를 무효화.
- 실제 진단 결과만 보고서에 저장·표시하며 예시 학생과 고정 판정을 제거.
- 실제 원점수·평균 자료가 없는데 수치·역량·비교 그래프를 만들어 표시하던 처리 제거.
- 손상된 브라우저 저장값과 자료 형식을 검증하고 분석 중 다음 단계 진입을 차단.
- 관리자 화면·서버의 권한 판정을 일치시키고 운영 인증 비밀값이 없을 때 공개 기본값을 사용하지 않도록 수정.
- 관리자 권한 확인에 불필요한 로컬 파일 쓰기를 제거.
- 실제 학원명만으로 이용권을 우회하거나 조회 장애 시 자동 허용하던 경로 제거. 명시적 demo_academy는 기존 공개 데모로 유지.
- 학생 학교명을 학원 ID로 사용하던 오류 제거.
- 파일 저장소 설정과 전체 이력 조회는 관리자 권한을 확인.
- PDF 비공개 보관과 다운로드, OCR 자원 해제·실패 처리 보완.
- PDF AI 추출 지침을 명시하고 검증된 과목·이수단위로 평균을 직접 계산.
- 메일 보고서의 HTML 삽입 방지, 수신자·본문 검증.
- 저장소 인증 토큰 만료 시 재인증하고 잘못된 자격의 무조건 우회 제거.
- 브라우저의 정상 관리자 업로드가 내부 주소 비교로 차단되던 오류 수정. 외부 출처 차단은 유지.
- 보고서의 상향/위험 판정이 안전 색상으로 표시되던 오류와 근거 글자 크기를 수정. 추세 자료 없음과 보합을 구분.
- 기존 직접 반영 스크립트도 관리자 화면과 같은 검증기를 사용하도록 통합. 기본은 검증 모드이며 2027 CSV에 2026 수치를 덮어쓰거나 다른 프로젝트로 자동 복사하지 않음.

| 검사 | 확인 결과 |
|---|---|
| 배포용 빌드 | npm run build 통과, 전체 라우트 생성 및 타입 검사 완료 |
| 앱 정적 검사 | npm run lint -- --quiet 통과, 오류 0 |
| 회귀 테스트 | npm test: 44개 통과, 실패 0 |

| 실제 HTTP·브라우저 검사 | 최종 빌드에서 업로드·반영·복원·권한 거부·실제 진단·보고서·수정 후 무효화 모두 통과, 페이지 실행 오류 0 |

외부 글꼴 리소스의 응답 지연은 브라우저 검사에서 제외하며 앱의 로컬 화면·동작을 검사한다. 실제 운영 DB·AI·메일·결제 자격으로 외부 호출하거나 운영 데이터와 배포를 변경하지 않았다.

## 운영 적용 전 남은 범위

- 마스터·본사·학원·담당자별 실제 계정 역할, 학원 간 접근 분리와 학생 배정 구현.
- 프로필·구독·주문·사용량의 로컬 파일 저장을 영구 운영 저장소로 통합.
- 실제 로그인·PocketBase·AI·메일·결제 설정과 운영 접근 규칙 확인.
- 공통 입결은 관리자가 검증 후 반영. 이번 V7.24 검사는 별도 임시 저장소에서 수행하며 원본과 운영 데이터를 변경하지 않음.
- GitHub/Vercel 운영 반영과 배포 후 확인은 별도 단계.

로컬 빌드·검사 통과를 다학원 운영 체계의 완성이나 운영 배포 완료로 표시하지 않는다.

## 실제 화면 검증 기록

시험용 관리자와 별도 임시 저장소에서 V7.24 26,410행·164개 대학을 실제 브라우저로 업로드·미리보기·반영했다. DGIST 기초학부 일반전형을 선택하여 실제 진단을 실행하고 보고서를 확인했다. 전형 수정 후 저장된 결과가 무효화되고 예시 학생이 표시되지 않는 것도 확인했다.

화면 기록은 로컬 outputs/qa/admin-admissions.png, diagnosis-step4.png, actual-report.png에 보관한다. 이 디렉터리는 배포 대상이 아니다. 시험 서버·브라우저·임시 데이터는 종료·정리했다. 운영 데이터는 변경하지 않았다.
